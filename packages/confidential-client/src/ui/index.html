    A record of the checks performed locally. Expected constraints are labelled separately from observations; this is not a raw hardware quote.
    
        
    Protection and limits
    Keys reach only the independently verified, owner-authorized guest. Native policy blocks administrator exec and access to key helpers. Your local computer and Docker runtime remain trusted. Administrators can deny service. Enrollment does not provide global singleton enforcement or encrypted-disk rollback protection.
